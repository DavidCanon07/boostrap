# Ejercicio Bootstrap

Página web responsiva maquetada con [Bootstrap 5.3.3](https://getbootstrap.com/) (CDN). Ejercicio de la universidad para practicar la construcción rápida de interfaces.

## Contenido

- **Navbar** con enlaces a Inicio, Servicios y Contacto, colapsable en móvil.
- **Carrusel** de imágenes.
- **Sistema de grilla** con tarjetas (imagen, título y descripción): 3 columnas en escritorio, 2 en tablet y 1 en móvil.
- **Modal** que se abre desde un botón con un mensaje de bienvenida.
- **Clases utilitarias** como `shadow`, `rounded`, `fw-bold`, `bg-light`, `m-3` y `my-5`.

## Cómo ejecutarlo

Abre `index.html` en el navegador. Necesita conexión a internet para cargar Bootstrap desde el CDN.

## Estructura

```
index.html   Página completa
images/      Imágenes del carrusel y de las tarjetas
```
